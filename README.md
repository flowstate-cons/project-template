# Agent Project Template

A folder for working with two agents on one project.

## Use It
1. Download this repo as a ZIP and unzip it where you work. Rename the folder after the project.
2. Put the work in `project/`. For a code project, clone its repo there.
3. Fill in `AGENTS.md`: swap the example line for who plays Lead and Maker on this project.
4. Point both agents at the renamed folder and tell them to read `AGENTS.md`.

## What's Inside
- `AGENTS.md`: how the agents work together.
- `RULES.md`: the user's rules for this project.
- `workspace/`: `directives.md` (what to do now), `board.md` (agent-to-agent notes) and `submissions/` (drafts for the Knowledge Library). This is the talk, and it never ships.
- `project/`: the work.

When a project ends, move `workspace/submissions/` into the shared Knowledge Submissions folder, then clear `workspace/` and keep anything worth carrying in `RULES.md`.
